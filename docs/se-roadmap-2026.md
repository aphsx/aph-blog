## Phase 2: Coding Interview Practice (สัปดาห์ 7-14)

> ฝึก LeetCode ตาม Grind 75 / NeetCode 150

### เป้าหมาย
- Easy: 30+ ข้อ (ทำได้ภายใน 15-20 นาที)
- Medium: 50+ ข้อ (ทำได้ภายใน 30-35 นาที)
- Hard: 5-10 ข้อ (สำหรับ FAANG)

### Must-Do Problems (Grind 75 — สำคัญที่สุด)

**Week 7-8 (Easy Problems)**
- Two Sum
- Valid Parentheses
- Merge Two Sorted Lists
- Best Time to Buy and Sell Stock
- Valid Palindrome
- Invert Binary Tree
- Binary Search
- Linked List Cycle
- Balanced Binary Tree
- Maximum Depth of Binary Tree

**Week 9-10 (Medium Problems)**
- Maximum Subarray
- Longest Substring Without Repeating Characters
- 3Sum
- Binary Tree Level Order Traversal
- Number of Islands
- Search in Rotated Sorted Array
- Coin Change
- Validate BST

**Week 11-12 (Medium-Hard)**
- LRU Cache
- Word Break
- Course Schedule (Topological Sort)
- Minimum Window Substring
- Merge Intervals
- Combination Sum
- Implement Trie

**Week 13-14: Mock Interviews**
- [Pramp](https://www.pramp.com/) — Mock interview ฟรีกับคนจริง
- [interviewing.io](https://interviewing.io/) — กับ engineer จาก FAANG
- ฝึกพูดอธิบายแนวคิดขณะแก้โจทย์ (Think aloud)

### Framework การแก้โจทย์ (UMPIRE Method)
1. **U**nderstand — อ่านโจทย์ ถามให้ชัด
2. **M**atch — จับ pattern ว่าเหมือน problem ไหน
3. **P**lan — วาง pseudocode ก่อน code จริง
4. **I**mplement — เขียน code
5. **R**eview — ตรวจ edge cases
6. **E**valuate — วิเคราะห์ Time/Space complexity

### แหล่งฝึก
- [LeetCode](https://leetcode.com/) — หลัก
- [NeetCode 150](https://neetcode.io/practice) — curated list
- [Grind 75](https://www.techinterviewhandbook.org/grind75/) — ปรับตามเวลาได้

## Phase 3: System Design (สัปดาห์ 15-18)

> สำคัญสำหรับ Mid-Senior level / บริษัทใหญ่

### หัวข้อที่ต้องรู้
- **Scalability**: Horizontal vs Vertical Scaling
- **Load Balancing**: Round-robin, Consistent Hashing
- **Databases**: SQL vs NoSQL, Sharding, Replication, Indexing
- **Caching**: Redis, Memcached, CDN, Cache invalidation
- **Message Queues**: Kafka, RabbitMQ, Pub/Sub
- **APIs**: REST, GraphQL, gRPC
- **Microservices vs Monolith**
- **CAP Theorem**
- **Rate Limiting**
- **Consistent Hashing**

### 2026 Additions — หัวข้อใหม่ที่ถูกถามเพิ่ม
- **Vector Databases** (Pinecone, Weaviate) — สำหรับ AI/ML systems
- **LLM Integration patterns** — RAG, embedding pipelines
- **Event-driven architecture**
- **Edge computing / CDN design**

### ระบบที่ต้องฝึก Design
1. URL Shortener (เริ่มง่าย)
2. Twitter / News Feed
3. YouTube / Netflix
4. WhatsApp / Chat system
5. Uber / Location-based service
6. Google Drive / File storage
7. Search Autocomplete

### แหล่งเรียน System Design
- [System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer) — ฟรี ครอบคลุมมาก
- [ByteByteGo](https://bytebytego.com/) — อธิบายด้วยภาพ เข้าใจง่าย
- [Grokking Modern System Design](https://www.educative.io/courses/grokking-modern-system-design-interview-for-engineers-managers)

## Phase 4: Projects + Portfolio (สัปดาห์ 19-22)

> ในปี 2026 Portfolio คือ "หลักฐาน" ที่สำคัญมาก

### Projects ที่แนะนำ (เลือก 2-3 ชิ้น)

**ระดับ Beginner**
- Todo App (CRUD พื้นฐาน)
- Weather App (เรียก API)
- Calculator

**ระดับ Intermediate (แนะนำ)**
- Full-stack Blog / CMS (React + Node.js/FastAPI + PostgreSQL)
- Real-time Chat App (WebSocket)
- E-commerce ขนาดเล็ก (auth, cart, payment)
- REST API with authentication (JWT)

**ระดับ Advanced + 2026 Trends**
- AI-powered App (RAG chatbot, document Q&A)
- Clone of real app (Notion clone, GitHub clone)
- Open Source contribution

### Tech Stack แนะนำ 2026

**Frontend:** React.js หรือ Next.js (TypeScript)
**Backend:** Node.js (Express/Fastify) หรือ Python (FastAPI)
**Database:** PostgreSQL + Redis
**DevOps:** Docker, GitHub Actions CI/CD
**Cloud:** AWS / GCP / Vercel (deploy จริง)

### Portfolio Website
- ใช้ GitHub Pages, Vercel, หรือ Netlify
- ต้องมี: About, Projects (with live demo + source code), Skills, Contact
- แนะนำ: [portfolio.dev](https://portfolio.dev/) เป็น inspiration

## Phase 5: Resume + LinkedIn + Job Applications (สัปดาห์ 23-26)

### Resume 2026

**หลักการ:**
- 1 หน้าเท่านั้น (ถ้าประสบการณ์ < 10 ปี)
- ใช้ format แบบ ATS-friendly (simple columns ไม่มี graphics)
- เขียน bullet points ด้วย format: **Accomplished [X] by doing [Y] resulting in [Z]**
- ใส่ตัวเลขทุกครั้งที่ทำได้: "Reduced load time by 40%", "Built API serving 10k req/day"

**สิ่งที่ต้องมีใน Resume:**
- Contact (Email, GitHub, LinkedIn, Portfolio)
- Education
- Skills (Languages, Frameworks, Tools, Cloud)
- Projects (2-3 ชิ้น สำคัญที่สุด)
- Experience (internship / part-time / freelance ก็ได้)

**เครื่องมือ:**
- [Resume.io](https://resume.io/)
- [Enhancv](https://enhancv.com/)
- LaTeX (ดูเป็น professional มาก)

### LinkedIn Profile Checklist
- [ ] Professional photo
- [ ] Headline ชัดเจน: "Software Engineer | Python | React | Open to Work"
- [ ] About section (3-5 ประโยค)
- [ ] Skills: 10+ ที่เกี่ยวข้อง
- [ ] Projects ใส่ลิงก์ GitHub
- [ ] Connections 200+ (เพิ่ม recruiter, engineers)
- [ ] เปิด "Open to Work" (visible to recruiters)

### Job Application Strategy
1. **Target 5-10 companies/สัปดาห์** — ไม่ใช่ 100 แบบ spray and pray
2. **Prioritize:** Referral > Direct Apply > Job Boards
3. **Job Boards:** LinkedIn Jobs, Glassdoor, Indeed, Levels.fyi, Wellfound (startup)
4. **Thailand Specific:** JobsDB, JobThai, Jobtopgun, Blognone Jobs
5. **Networking:** ไปงาน Tech meetup, ใช้ Discord/Slack community

## Interview Process ที่ต้องเตรียม

### 1. Phone Screen / HR Round
- ทำไมอยากทำงานที่นี่?
- เล่าเกี่ยวกับตัวเอง (Self Introduction 2 นาที)
- Expected salary

### 2. Technical Screen (Coding)
- 1-2 LeetCode problems (45-60 นาที)
- อธิบายขณะแก้ (think aloud)
- ถามถึง edge cases, complexity

### 3. System Design Round (Mid/Senior)
- ออกแบบระบบใหญ่ใน 45-60 นาที
- เน้น: requirements gathering → high-level design → deep dive

### 4. Behavioral Round (STAR Method)
สำหรับแต่ละคำถาม ตอบด้วย:
- **S**ituation — บริบทคืออะไร
- **T**ask — งานที่ต้องทำคืออะไร
- **A**ction — คุณทำอะไร
- **R**esult — ผลลัพธ์เป็นอย่างไร

**คำถามที่มักถาม:**
- Tell me about a challenging project
- Tell me about a time you disagreed with your team
- How do you handle tight deadlines?
- Tell me about a mistake you made

### Self Introduction Template (2026)
```
"Hi, I'm [Name]. I'm a software engineer with a focus on [specialty, e.g., backend / full-stack].
I recently [built / worked on] [project] using [tech stack], where I [key achievement].
Before that, I [background/education]. 
I'm excited about this opportunity because [specific reason].
I'm looking forward to [contributing X]."
```
