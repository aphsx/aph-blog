# Basic Data Structure - Part 2

ต่อจากบทที่แล้ว เราจะมาดูโครงสร้างข้อมูลที่ซับซ้อนขึ้น คือแบบ Non-linear (ไม่เป็นเส้นตรง)

เนื้อหา:
1.  **Tree:** โครงสร้างต้นไม้, Binary Tree, Binary Search Tree (BST)
2.  **Graph:** โครงสร้างเครือข่าย, Node และ Edge, การแทน Graph (Adjacency Matrix/List)
3.  **Heap:** Tree พิเศษสำหรับหาค่ามากสุด/น้อยสุดได้อย่างรวดเร็ว

เรื่องนี้เป็นพื้นฐานสำคัญของ Algorithm ขั้นสูงมากมายครับ
