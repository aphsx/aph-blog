# Basic Data Structure - Part 1

Data Structure คือวิธีจัดเก็บข้อมูลเพื่อให้ใช้งานได้อย่างมีประสิทธิภาพ ในบทนี้เราจะสร้าง Data Structure ขึ้นมาเองจากศูนย์ (โดยใช้ Pointer และ Struct ที่เรียนไป)

เนื้อหา:
1.  **Linked List:** โซ่ข้อความที่ต่อกันไม่รู้จบ (Singly, Doubly)
2.  **Stack:** กองซ้อนข้อมูล (LIFO - Last In First Out)
3.  **Queue:** การเข้าคิว (FIFO - First In First Out)

เราจะเรียนทั้งทฤษฎีและการ Implement ด้วย C++ ครับ
