# Basic Problem Solving

ในบทนี้เราจะพักเรื่อง Syntax ใหม่ๆ ไว้ก่อน และมาเน้นที่การ "นำสิ่งที่รู้มาใช้แก้ปัญหา"

สิ่งที่จะได้เรียนรู้:
1.  **Algorithmic Thinking:** การคิดเป็นลำดับขั้นตอน
2.  **Flowchart & Pseudocode:** การเขียนแผนภาพและรหัสเทียม
3.  **Practice Problems:** ตะลุยโจทย์พื้นฐาน (หา Min/Max, หาผลรวม, วาดรูปดาว)

เตรียมตัวให้พร้อมสำหรับการฝึกสมองครับ!
