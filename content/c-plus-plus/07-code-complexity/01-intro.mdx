# Code Complexity (Big O Notation)

เขียนโปรแกรมให้ทำงานได้นั้นไม่พอ ต้องทำงานได้ "เร็ว" และ "ประหยัดทรัพยากร" ด้วย

เนื้อหา:
1.  **Time Complexity:** โปรแกรมทำงานนานแค่ไหนเมื่อข้อมูลเยอะขึ้น?
2.  **Space Complexity:** โปรแกรมกิน Ram เยอะแค่ไหน?
3.  **Big O Notation:** O(1), O(n), O(log n), O(n^2) คืออะไร? อ่านกราฟยังไง?
