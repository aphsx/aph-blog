# Pointer, Vector, Struct & OOP

บทนี้คือจุดเปลี่ยนจาก "ผู้เริ่มต้น" สู่ "โปรแกรมเมอร์ C++ ตัวจริง" เราจะเรียนเรื่องที่ยากแต่ทรงพลังที่สุดของ C++

เนื้อหา:
1.  **Pointers:** การจัดการ Memory Address แบบถึงลูกถึงคน
2.  **Vector:** Array แบบยืดหยุ่นที่ชีวิตขาดไม่ได้
3.  **Struct:** การสร้างชนิดข้อมูลใหม่ของเราเอง
4.  **OOP (Object Oriented Programming):** Class, Object, Inheritance, Polymorphism

เตรียมใจไว้เลยว่าเรื่อง Pointer อาจจะงงในตอนแรก แต่ถ้าเข้าใจแล้ว คุณจะครองโลก C++ ได้ครับ
