# Dynamic Programming (DP)

DP คือยาขมของนักเรียนคอมพิวเตอร์ทั่วโลก แต่ถ้าเข้าใจแล้วมันคือเวทมนตร์! หลักการคือ "อย่าคำนวณซ้ำ" (Don't repeat yourself)

เนื้อหา:
1.  **Concept:** Overlapping Subproblems & Optimal Substructure
2.  **Memoization (Top-down):** จดจำคำตอบไว้ในตาราง
3.  **Tabulation (Bottom-up):** สร้างคำตอบจากเล็กไปใหญ่
4.  **Classic Problems:** Fibonacci, 0/1 Knapsack, Longest Common Subsequence (LCS)

เตรียมสมองให้พร้อม เพราะบทนี้ต้องใช้จินตนาการสูงมาก
