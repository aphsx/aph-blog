# Functions

ฟังก์ชัน (Function) คือกลุ่มของคำสั่งที่ถูกเขียนแยกออกมาเพื่อทำงานเฉพาะอย่าง ช่วยให้โค้ดเป็นระเบียบ อ่านง่าย และนำกลับมาใช้ซ้ำ (Reuse) ได้

## 1. การสร้างและเรียกใช้ฟังก์ชัน

รูปแบบ:
```cpp
returnType functionName(parameter1, parameter2, ...) {
  // code to be executed
  return value;
}
```

ตัวอย่าง:
```cpp
#include <iostream>
using namespace std;

// สร้างฟังก์ชัน (Definition)
void sayHello() {
    cout << "Hello Function!" << endl;
}

int main() {
    sayHello(); // เรียกใช้ฟังก์ชัน (Call)
    sayHello(); 
    return 0;
}
```

## 2. Parameter และ Arguments

เราส่งค่าเข้าไปให้ฟังก์ชันทำงานได้ผ่านทาง Parameter

```cpp
// fname คือ Parameter
void printName(string fname) {
    cout << fname << " Refsnes\n";
}

int main() {
    printName("Liam");  // "Liam" คือ Argument
    printName("Jenny");
    return 0;
}
```

## 3. Return Values

ฟังก์ชันส่งค่ากลับคืนมาได้ โดยเปลี่ยน `void` เป็นชนิดข้อมูลที่ต้องการ

```cpp
int myFunction(int x) {
    return 5 + x;
}

int main() {
    cout << myFunction(3); // แสดงผล 8
    return 0;
}
```

## 4. Pass by Value vs Pass by Reference

นี่คือจุดสำคัญของ C++!

*   **Pass by Value (ค่า Default):** ก๊อปปี้ค่าไปให้ฟังก์ชัน แก้ไขในฟังก์ชัน **ไม่กระทบ** ตัวจริง
*   **Pass by Reference (`&`):** ส่งที่อยู่ (Address) ไป แก้ไขในฟังก์ชัน **กระทบ** ตัวจริง

```cpp
void swapNums(int &x, int &y) { // สังเกตเครื่องหมาย &
  int z = x;
  x = y;
  y = z;
}

int main() {
  int firstNum = 10;
  int secondNum = 20;

  swapNums(firstNum, secondNum);

  cout << firstNum << secondNum; // ผลลัพธ์: 20 10 (สลับกันจริง)
  return 0;
}
```

## 5. Function Overloading

ชื่อฟังก์ชันเหมือนกันได้ แต่ต้องมี Parameter ต่างกัน (จำนวน หรือ ชนิดข้อมูล)

```cpp
int plusFunc(int x, int y) {
  return x + y;
}

double plusFunc(double x, double y) {
  return x + y;
}

// เรียกใช้ได้ทั้งคู่ Compiler จะเลือกให้เอง
```

## 6. Recursion (ฟังก์ชันเรียกตัวเอง)

ฟังก์ชันที่เรียกตัวเองซ้ำๆ มักใช้แก้ปัญหาที่ซับซ้อน เช่น การหา Factorial

```cpp
int factorial(int n) {
    if (n <= 1) return 1; // Base case (จุดหยุด)
    return n * factorial(n - 1); // Recursive case
}
```
