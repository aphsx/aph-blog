# Introduction to C++

ยินดีต้อนรับเข้าสู่บทเรียน C++ Programming! ในบทแรกนี้ เราจะมาทำความรู้จักกับภาษา C++ ว่าคืออะไร ทำไมถึงยังเป็นที่นิยม และเตรียมเครื่องมือสำหรับการเขียนโปรแกรมกันครับ

## 1. C++ คืออะไร?

C++ (ซี-พลัส-พลัส) เป็นภาษาโปรแกรมคอมพิวเตอร์อเนกประสงค์ (General-purpose programming language) ที่พัฒนาต่อยอดมาจากภาษา C โดย Bjarne Stroustrup ที่ Bell Labs ในปี 1979

### จุดเด่นของ C++
*   **Performance:** C++ เป็นภาษาที่ทำงานได้เร็วและมีประสิทธิภาพสูง เข้าถึงฮาร์ดแวร์ได้ในระดับต่ำ (Low-level access) จึงนิยมใช้ในการสร้าง Game Engine, Operating System, และระบบที่ต้องการความเร็วสูง
*   **Object-Oriented:** รองรับการเขียนโปรแกรมเชิงวัตถุ (OOP) อย่างเต็มรูปแบบ ช่วยให้จัดการโครงสร้างโค้ดที่ซับซ้อนได้ดี
*   **Standard Template Library (STL):** มีคลังไลบรารีมาตรฐานที่เตรียม Data Structure และ Algorithm พื้นฐานมาให้ใช้งานได้ทันที (เช่น Vector, Map, Sort) ซึ่งเราจะได้เรียนกันอย่างละเอียดในคอร์สนี้

## 2. การเตรียม Environment (Setup)

ในการเขียน C++ เราจำเป็นต้องมี 2 อย่างหลักๆ คือ
1.  **Text Editor / IDE:** สำหรับเขียนโค้ด
2.  **Compiler:** สำหรับแปลงโค้ดที่เราเขียนเป็นภาษาเครื่อง (Machine Code) ให้คอมพิวเตอร์ทำงาน

### แนะนำเครื่องมือ
*   **Visual Studio Code (VS Code):** Editor ยอดนิยม ปรับแต่งได้เยอะ (แนะนำสำหรับคอร์สนี้)
*   **Visual Studio (Community):** IDE ตัวเต็มจาก Microsoft ครบเครื่องแต่ไฟล์ใหญ่
*   **CLion:** IDE จาก JetBrains (มีค่าใช้จ่าย แต่ดีมาก)
*   **Dev-C++ / Code::Blocks:** เครื่องมือเก่าแก่ แนะนำให้เลี่ยงถ้าเป็นไปได้ เพราะไม่ได้อัปเดตมาตรฐานใหม่ๆ

### การติดตั้ง GCC Compiler (Windows - MinGW)
หากใช้ VS Code บน Windows คุณต้องติดตั้ง Compiler เอง ขั้นตอนคร่าวๆ คือ:
1.  ดาวน์โหลด **MinGW-w64** หรือ **MSYS2**
2.  ติดตั้งและเพิ่ม Path ใน Environment Variables
3.  ตรวจสอบโดยพิมพ์ `g++ --version` ใน Terminal

## 3. โปรแกรมแรก (Hello World)

มาลองเขียนโปรแกรมแรกกันครับ ไฟล์นามสกุลของ C++ คือ `.cpp`

สร้างไฟล์ชื่อ `hello.cpp` และพิมพ์โค้ดดังนี้:

```cpp showLineNumbers title="hello.cpp"
#include <iostream> // Library สำหรับ Input/Output

int main() {
    // แสดงข้อความ Hello C++ ออกทางหน้าจอ
    std::cout << "Hello C++ Data Structure & Algorithm!" << std::endl;
    
    return 0; // จบการทำงานของโปรแกรมด้วยสถานะ 0 (Success)
}
```

### อธิบายโค้ด
*   `#include <iostream>`: เป็นการนำเข้า Header file ที่ชื่อ `iostream` เพื่อให้เราสามารถใช้งานคำสั่ง `cout` (Output) และ `cin` (Input) ได้
*   `int main() { ... }`: ฟังก์ชันหลักที่เป็นจุดเริ่มต้นของโปรแกรม ทุกโปรแกรม C++ ต้องมี `main`
*   `std::cout`: (Character Output) ใช้แสดงผลข้อความ
*   `<<`: Insertion operator ใช้ส่งข้อมูลไปที่ `cout`
*   `std::endl`: ใช้ขึ้นบรรทัดใหม่ (End Line)
*   `return 0;`: ส่งค่า 0 กลับไปบอกระบบปฏิบัติการว่าโปรแกรมทำงานเสร็จสมบูรณ์

## 4. การ Compile และ Run

เปิด Terminal แล้วพิมพ์คำสั่ง:

```bash
g++ hello.cpp -o hello
```
*   `g++` คือเรียกใช้ compiler
*   `hello.cpp` คือไฟล์ Source code
*   `-o hello` คือกำหนดชื่อไฟล์ผลลัพธ์ (Executable) เป็น `hello.exe`

จากนั้นสั่งรันโปรแกรม:
```bash
./hello
```

ผลลัพธ์:
```
Hello C++ Data Structure & Algorithm!
```

ยินดีด้วยครับ! คุณเขียน C++ เป็นแล้ว ในบทต่อไปเราจะมาดูเรื่อง Syntax และกฎพื้นฐานต่างๆ กันต่อครับ
