# Control Structures

เพื่อให้โปรแกรมของเราฉลาดขึ้น มันต้องรู้จัก "ตัดสินใจ" และ "ทำซ้ำ" ได้ นี่คือหัวใจของ Logic ในการเขียนโปรแกรมครับ

## 1. Conditional Statements (เงื่อนไข)

### if ... else
ใช้ตรวจสอบเงื่อนไข ถ้าจริงทำอย่างหนึ่ง ถ้าเท็จทำอีกอย่าง

```cpp
int score = 75;

if (score >= 80) {
    cout << "Grade A";
} else if (score >= 70) {
    cout << "Grade B";
} else {
    cout << "Grade C or lower";
}
```

### switch
ใช้เมื่อมีทางเลือกที่เป็นค่าคงที่ (เช่น ตัวเลข หรือ ตัวอักษร) หลายๆ ทาง

```cpp
int day = 3;
switch (day) {
  case 1:
    cout << "Monday";
    break; // อย่าลืม break! ไม่งั้นมันจะไหลไปทำ case ต่อไป
  case 2:
    cout << "Tuesday";
    break;
  default: // เหมือน else (กรณีไม่ตรงกับ case ไหนเลย)
    cout << "Other day";
}
```

## 2. Loops (การวนซ้ำ)

### for loop
ใช้เมื่อ **รู้จำนวนรอบที่แน่นอน**

```cpp
// พิมพ์ 0 ถึง 4
for (int i = 0; i < 5; i++) {
    cout << i << " ";
}
```

### while loop
ใช้เมื่อ **ไม่รู้จำนวนรอบ** แต่ทำตราบเท่าที่เงื่อนไขยังเป็นจริง

```cpp
int i = 0;
while (i < 5) {
    cout << i << " ";
    i++;
}
```

### do-while loop
เหมือน while แต่ **ทำก่อน 1 รอบ** แล้วค่อยเช็คเงื่อนไข

```cpp
int i = 0;
do {
    cout << i << " ";
    i++;
} while (i < 5);
```

## 3. Break และ Continue

*   `break`: หยุด Loop ทันที (กระโดดออกจาก Loop)
*   `continue`: ข้ามรอบปัจจุบัน แล้วไปเริ่มรอบถัดไปทันที

```cpp
for (int i = 0; i < 10; i++) {
  if (i == 4) break;    // เจอ 4 เลิกทำ (ผลลัพธ์: 0 1 2 3)
  if (i == 2) continue; // เจอ 2 ข้ามไป (ผลลัพธ์: 0 1 3 ...)
  cout << i << " ";
}
```

## 4. Short Hand If (Ternary Operator)
เขียน if-else แบบย่อในบรรทัดเดียว

`variable = (condition) ? expressionTrue : expressionFalse;`

```cpp
int time = 20;
string result = (time < 18) ? "Good day" : "Good evening";
cout << result;
```
