# Variables & Data Types

การเขียนโปรแกรมคือการจัดการกับ "ข้อมูล" ดังนั้นเราต้องรู้จักวิธีเก็บข้อมูลลงใน "ตัวแปร" (Variable) และระบุ "ชนิด" (Type) ของมันให้ถูกต้อง

## 1. การประกาศตัวแปร (Variable Declaration)

รูปแบบการประกาศตัวแปรใน C++:
`Type variableName = value;`

```cpp
int score = 100;       // จำนวนเต็ม
double price = 99.50;  // ทศนิยม
char grade = 'A';      // ตัวอักษรเดียว
bool isPass = true;    // ค่าความจริง (จริง/เท็จ)
```

## 2. Primitive Data Types

ชนิดข้อมูลพื้นฐานที่ใช้บ่อยใน C++ มีดังนี้:

| Type | ขนาด (โดยประมาณ) | เก็บข้อมูลอะไร? | ตัวอย่าง |
| :--- | :--- | :--- | :--- |
| `int` | 4 bytes | จำนวนเต็ม | `10`, `-5`, `0` |
| `float` | 4 bytes | ทศนิยม (ความแม่นยำต่ำ) | `3.14f`, `2.5f` |
| `double` | 8 bytes | ทศนิยม (ความแม่นยำสูง) | `3.14159`, `99.99` |
| `char` | 1 byte | ตัวอักษรเดียว (ใน ' ') | `'A'`, `'z'`, `'#'` |
| `bool` | 1 byte | ตรรกะ | `true`, `false` |
| `string` | - | ข้อความ (ต้อง `#include <string>`) | `"Hello World"` |

### ข้อควรระวังเรื่อง Integer Overflow
`int` ปกติเก็บค่าได้ประมาณ -2 พันล้าน ถึง +2 พันล้าน ถ้าต้องเก็บค่ามากกว่านี้ให้ใช้ `long long` (8 bytes)

```cpp
long long bigNumber = 9000000000000LL;
```

## 3. String (สตริง)

ใน C++ แบบใหม่ เรานิยมใช้ `std::string` มากกว่า C-style string (`char[]`) เพราะจัดการง่ายกว่า

```cpp
#include <iostream>
#include <string> // ต้อง include เสมอ

int main() {
    std::string firstName = "John";
    std::string lastName = "Doe";
    
    // การต่อข้อความ (Concatenation)
    std::string fullName = firstName + " " + lastName;
    
    std::cout << fullName.length(); // หาความยาวได้ง่ายๆ
    return 0;
}
```

## 4. Constants (ค่าคงที่)

ถ้าต้องการประกาศตัวแปรที่ **ห้ามแก้ไขค่า** ให้ใช้ keyword `const` นำหน้า

```cpp
const double PI = 3.14159;
// PI = 3.14; // Error! แก้ไขค่าไม่ได้
```

หรือใช้ `#define` (แบบเก่า ไม่แนะนำเท่าไหร่ แต่ควรรู้ไว้)
```cpp
#define MAX_SCORE 100
```

## 5. Type Conversion (การแปลงชนิดข้อมูล)

### Implicit (อัตโนมัติ)
เกิดขึ้นเมื่อนำ type เล็กไปใส่ type ใหญ่
```cpp
int myInt = 9;
double myDouble = myInt; // กลายเป็น 9.0 อัตโนมัติ
```

### Explicit (บังคับแปลง)
```cpp
double myDouble = 9.78;
int myInt = (int)myDouble; // เหลือ 9 (ตัดทศนิยมทิ้ง)
```

## สรุป
*   เลือกใช้ Type ให้เหมาะสมกับข้อมูล
*   ใช้ `string` แทน `char` array เพื่อชีวิตที่ง่ายขึ้น
*   ใช้ `const` เสมอถ้าค่าไม่ควรเปลี่ยน
