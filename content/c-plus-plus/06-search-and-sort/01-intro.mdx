# Search & Sort

Algorithm คือขั้นตอนวิธีในการแก้ปัญหา ในบทนี้เราจะเริ่มที่ปัญหาสุดคลาสสิกของคอมพิวเตอร์: การหาของ (Search) และ การจัดเรียงของ (Sort)

เนื้อหา:
1.  **Searching:** Linear Search vs Binary Search
2.  **Sorting (Basic):** Bubble Sort, Selection Sort, Insertion Sort
3.  **Sorting (Advanced):** Merge Sort, Quick Sort (จะพูดถึง concept คร่าวๆ ก่อนเจาะลึกในบท Divide & Conquer)

เราจะได้เห็นว่า Algorithm ที่ดีทำให้โปรแกรมเร็วขึ้นเป็นล้านเท่าได้อย่างไร
