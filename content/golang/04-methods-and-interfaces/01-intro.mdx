# Methods & Interfaces

Go ไม่ใช่ภาษา OOP แบบดั้งเดิม (ไม่มี Class, ไม่มี Extends) แต่เราทำ OOP ได้ด้วย **Methods** และ **Interfaces**

เนื้อหา:
1.  **Methods:** การผูกฟังก์ชันเข้ากับ Struct (Receiver function)
2.  **Interfaces:** สัญญาระหว่าง Type (Duck Typing: "ถ้ามันเดินเหมือนเป็ด ร้องเหมือนเป็ด มันก็คือเป็ด")
3.  **Empty Interface (`interface{}`):** ตัวแปรที่เก็บได้ทุกอย่าง

Interfaces คือหัวใจสำคัญที่ทำให้ Go ยืดหยุ่นและ Test ง่าย
