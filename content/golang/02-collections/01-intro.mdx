# Collections

ในบทนี้เราจะเรียนรู้วิธีเก็บข้อมูลหลายๆ ตัวใน Go ซึ่งมีตัวพระเอกคือ **Slice** และ **Map**

เนื้อหา:
1.  **Array:** ขนาดคงที่ (ไม่ค่อยได้ใช้ตรงๆ)
2.  **Slice:** Array ที่ยืดหดได้ (พระเอกของงาน) การใช้ `make`, `append`, `copy`
3.  **Map:** Key-Value pair (เหมือน Dictionary หรือ HashMap)
4.  **Range:** การวนลูปข้อมูลใน Collection

Slice คือสิ่งที่ทำให้ Go เขียนสนุกและยืดหยุ่นมากครับ
