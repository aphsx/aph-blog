# Error Handling

"Go ไม่มี Exception" (Try-Catch) แต่เราใช้การ Return Error ออกมาเป็นค่าหนึ่งแทน

เนื้อหา:
1.  **The Error Interface:** `error` type คืออะไร
2.  **Check Error:** Pattern การเช็ค `if err != nil`
3.  **Panic & Recover:** การรับมือกับ Critical Error (คล้าย Try-Catch แต่ใช้เฉพาะที่จำเป็น)

บทนี้จะเปลี่ยน Mindset การเขียน Error Handling ของคุณไปเลย
