# Pointers & Structs

Go เป็นภาษาที่มี Pointer (เหมือน C) แต่ปลอดภัยกว่าและใช้ง่ายกว่า

เนื้อหา:
1.  **Pointers:** `&` (Address of) และ `*` (Value at address) คืออะไร?
2.  **Structs:** การสร้าง Custom Type (คล้าย Class แต่ไม่มี Inheritance)
3.  **Struct Literals:** วิธีสร้าง Struct แบบต่างๆ

เราจะใช้ Struct เป็นพื้นฐานในการสร้าง Object ในบทถัดไป
