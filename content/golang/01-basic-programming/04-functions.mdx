# Functions

ฟังก์ชันใน Go เป็น "First-class citizen" คือส่งเป็น parameter ได้, return ออกมาได้ และเก็บในตัวแปรได้

## 1. การประกาศฟังก์ชัน

```go
func add(x int, y int) int {
    return x + y
}

// ถ้ารับ Type เดียวกัน เขียนย่อได้
func multiply(x, y int) int {
    return x * y
}
```

## 2. Multiple Return Values ✨

นี่คือทีเด็ดของ Go! ฟังก์ชันสามารถ return ค่ากลับมาได้มากกว่า 1 ค่า นิยมใช้กับการ return `(ค่าผลลัพธ์, error)`

```go
func swap(x, y string) (string, string) {
    return y, x
}

func main() {
    a, b := swap("Hello", "World")
    fmt.Println(a, b) // World Hello
}
```

## 3. Named Return Values

เราสามารถตั้งชื่อให้ตัวแปร return ได้เลย (Go จะประกาศตัวแปรนั้นให้อัตโนมัติ)

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return // "Naked return" มันจะ return x, y เองอัตโนมัติ
}
```

## 4. Variadic Functions

ฟังก์ชันที่รับจำนวน parameter ไม่จำกัด (เหมือน `fmt.Println`)

```go
func sum(nums ...int) int { // nums จะกลายเป็น slice []int
    total := 0
    for _, num := range nums {
        total += num
    }
    return total
}

func main() {
    fmt.Println(sum(1, 2))       // 3
    fmt.Println(sum(1, 2, 3, 4)) // 10
}
```

## 5. Anonymous Functions (Lambda)

ฟังก์ชันไม่มีชื่อ สามารถประกาศและเรียกใช้ได้ทันที หรือเก็บในตัวแปร

```go
func main() {
    // ประกาศและเรียกใช้ทันที
    func(msg string) {
        fmt.Println(msg)
    }("Hello Anonymous")
    
    // เก็บในตัวแปร
    double := func(x int) int {
        return x * 2
    }
    fmt.Println(double(5)) // 10
}
```
