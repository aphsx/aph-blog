# Control Structures

Go ออกแบบมาให้มี Keyword น้อยที่สุด ดังนั้น Control Structure จึงเรียบง่ายแต่ทรงพลัง

## 1. If ... Else

ไม่ต้องใส่วงเล็บ `()` ที่เงื่อนไข แต่ต้องมีปีกกา `{}` เสมอ

```go
score := 75

if score >= 80 {
    fmt.Println("A")
} else if score >= 70 {
    fmt.Println("B")
} else {
    fmt.Println("C")
}
```

### If with Short Statement
เราสามารถประกาศตัวแปรสั้นๆ ก่อนเช็คเงื่อนไขได้ (ตัวแปรนี้จะใช้ได้แค่ใน block if-else นี้)

```go
// เช็คว่า 10 หาร 2 ลงตัวไหม
if result := 10 % 2; result == 0 {
    fmt.Println("Even number")
} else {
    fmt.Println("Odd number, remainder:", result)
}
```

## 2. Switch

Switch ของ Go ฉลาดมาก
*   ไม่ต้องใส่ `break` (มัน break ให้อัตโนมัติ)
*   ถ้าอยากให้ไหลไป case ล่าง ต้องใช้ `fallthrough` (ซึ่งไม่ค่อยใช้)
*   ใช้กับเงื่อนไขอะไรก็ได้ ไม่จำกัดแค่ค่าคงที่

```go
day := "Monday"

switch day {
case "Monday":
    fmt.Println("Start work!")
case "Friday":
    fmt.Println("Party time!")
default:
    fmt.Println("Normal day")
}
```

แบบไม่มี condition (ใช้แทน if-else ยาวๆ)
```go
t := time.Now().Hour()
switch {
case t < 12:
    fmt.Println("Morning")
case t < 17:
    fmt.Println("Afternoon")
default:
    fmt.Println("Evening")
}
```

## 3. For Loop

Go **มี Loop แค่แบบเดียว** คือ `for` (ไม่มี while, ไม่มี do-while) แต่ for ของ Go เป็นได้ทุกอย่าง

### แบบมาตรฐาน (C-Style)
```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

### แบบ While Loop
```go
count := 1
for count < 5 { // ละส่วนต้นและส่วนท้ายไว้
    count *= 2
}
```

### แบบ Infinite Loop (While True)
```go
for {
    fmt.Println("Loop forever...")
    break // ต้องมี break เพื่อออก
}
```

## 4. Defer

`defer` เป็นคำสั่งพิเศษของ Go ใช้สั่งให้ฟังก์ชันทำงาน **"หลังจากจบฟังก์ชันหลัก"** นิยมใช้กับการปิดไฟล์, ปิด Database connection

```go
func main() {
    fmt.Println("Start")
    
    defer fmt.Println("End") // บรรทัดนี้จะทำงานเป็นลำดับสุดท้าย ก่อนออกจาก main
    
    fmt.Println("Working...")
}
```
**ผลลัพธ์:**
```
Start
Working...
End
```

:::info
ถ้ามี defer หลายตัว จะทำงานแบบ **Stack** (เข้าหลัง-ออกก่อน)
:::
