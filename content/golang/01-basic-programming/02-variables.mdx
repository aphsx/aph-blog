# Variables & Data Types

Go เป็นภาษาแบบ **Statically Typed** คือต้องระบุชนิดข้อมูลของตัวแปร (แต่ Compiler ช่วยเดาให้ได้) และมีความเข้มงวดสูงมาก "ประกาศแล้วต้องใช้" ถ้าไม่ใช้จะ Compile ไม่ผ่าน!

## 1. การประกาศตัวแปร (Variables)

มี 2 วิธีหลักๆ:

### แบบเต็ม (Full Declaration)
ใช้ keyword `var` เหมาะสำหรับประกาศตัวแปรก่อน แล้วค่อยกำหนดค่าทีหลัง หรือประกาศระดับ Global

```go
var age int          // ประกาศแต่ยังไม่กำหนดค่า (จะเป็น 0)
var name string = "John" // ประกาศพร้อมกำหนดค่า
```

### แบบย่อ (Short Declaration)
ใช้ `:=` (Walrus Operator) **นิยมใช้ที่สุด** ในฟังก์ชัน

```go
func main() {
    score := 100        // Go รู้เองว่าเป็น int
    message := "Hello"  // Go รู้เองว่าเป็น string
    
    // score := 200     // Error! ห้ามประกาศซ้ำ
    score = 200         // แก้ไขค่าได้ปกติ
}
```

## 2. Basic Data Types

| Type | Description | Zero Value (ค่าเริ่มต้น) |
| :--- | :--- | :--- |
| `int`, `int64` | จำนวนเต็ม | `0` |
| `float64` | ทศนิยม (มาตรฐาน) | `0.0` |
| `bool` | จริง/เท็จ | `false` |
| `string` | ข้อความ | `""` (Empty string) |

### Zero Values
จุดเด่นของ Go คือตัวแปรทุกตัวจะมีค่าเริ่มต้นเสมอ ไม่มีการเป็น `null` หรือ `undefined` แบบคาดเดาไม่ได้

```go
var x int
var y string
var z bool

fmt.Println(x) // 0
fmt.Println(y) // "" (ว่างเปล่า)
fmt.Println(z) // false
```

## 3. Constants (ค่าคงที่)

ใช้ `const` ตัวแปรเหล่านี้ค่าจะถูกฝังตอน Compile และแก้ไขไม่ได้

```go
const Pi = 3.14159
const AppName = "MySuperApp"
```

## 4. Type Conversion

Go **ไม่มี** การแปลง Type อัตโนมัติ (Implicit Casting) แม้แต่ int กับ float ก็บวกกันตรงๆ ไม่ได้ ต้องแปลงก่อนเสมอ

```go
var i int = 42
var f float64 = float64(i) // ต้องแปลงแบบชัดเจน
var u uint = uint(f)
```

## 5. Multiple Variable Declaration

ประกาศหลายตัวพร้อมกันได้ เพื่อความสะอาดของโค้ด

```go
var (
    firstName = "Somchai"
    lastName  = "Jaidee"
    age       = 30
)
```

:::tip
**จำไว้เสมอ:** ใน Go ถ้าประกาศตัวแปรแล้ว **ต้องถูกเรียกใช้** ไม่งั้นจะเกิด Compile Error "declared and not used" นี่คือวิธีที่ Go บังคับให้เราเขียนโค้ดสะอาดครับ
:::
