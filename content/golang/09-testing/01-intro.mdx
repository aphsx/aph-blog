# Testing

Go ให้ความสำคัญกับ Quality มาก จึงมี Testing Tool ติดมากับภาษาเลย

เนื้อหา:
1.  **Unit Test (`_test.go`):** การเขียน Test function
2.  **Table Driven Tests:** Pattern การเขียน Test ยอดนิยมของ Go
3.  **Benchmark:** วัดความเร็วโค้ดแบบแม่นยำ
4.  **Test Coverage:** เช็คว่า Test ครอบคลุมแค่ไหน

เขียน Code ดี ต้องมี Test ครับ!
