# Modules & Packages

เมื่อโปรเจกต์ใหญ่ขึ้น เราต้องรู้จักแบ่งโค้ดเป็นส่วนๆ และเรียกใช้ Library ชาวบ้าน

เนื้อหา:
1.  **Go Modules (`go.mod`):** ระบบจัดการ Dependency มาตรฐาน
2.  **Packages:** การสร้างและ import package
3.  **Exported/Unexported:** กฎตัวพิมพ์ใหญ่/เล็ก (Public/Private)
4.  **Project Structure:** โครงสร้างโฟลเดอร์มาตรฐาน (Standard Go Project Layout)

บทนี้จะทำให้คุณทำงานเป็นทีมและขึ้นโปรเจกต์จริงได้
