# Web Fundamentals

Go เกิดมาเพื่อทำ Web Backend! เราจะมาลองสร้าง Web Server กัน

เนื้อหา:
1.  **net/http:** Standard Library สำหรับทำ Web Server (ไม่ต้องง้อ Framework!)
2.  **JSON Handling:** การแปลง Struct <-> JSON (Marshal/Unmarshal)
3.  **Routing:** การจัดการ URL Path
4.  **Middleware:** ตัวแทรกการทำงาน (เช่น Log, Auth)

คุณจะทึ่งว่าแค่ Standard Library ก็ทำเว็บได้ครบเครื่องแล้ว
